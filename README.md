# [Kursy Guide](https://kursyguide.com/ru/)

Kursy Guide: независимый каталог и подборки онлайн-курсов для бизнеса и работы. Языки каталога и подборок: украинский, русский для Украины и английский.

- 282 курса
- 56 школ
- 31 тема, в том числе Google Ads, SMM, ИИ в маркетинге, графический и веб-дизайн, фотография, копирайтинг, проектный менеджмент, Power BI и email-маркетинг
- Сравнение по программе, языку, формату и поддержке
- 110 отзывов с источниками
- Подборки для владельцев бизнеса и для бесплатного обучения

Факты взяты со страниц школ и материалов програм.
